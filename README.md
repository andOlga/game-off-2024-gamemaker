# Secret Entrances, Confounding Rooms: Enfer's Trial

This is the original GameMaker version of the game we created for Game Off 2024, theme "Secret". A minimalistic, action-based dungeon crawler.

You may play the game [here](https://gx.games/games/tpycl9/secret-entrances-confounding-rooms-enfer-s-trial/).

An experimental, unfinished [Godot remake](https://github.com/andOlga/game-off-2024-godot) created for the sake of learning that engine, is also available.
